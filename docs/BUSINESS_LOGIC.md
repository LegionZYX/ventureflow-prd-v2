# VentureFlow - 业务逻辑说明

## 📖 项目概述

VentureFlow 是一个**字节跳动股权二级市场交易平台**的演示系统，为 FA（财务顾问）、经纪人和投资者提供完整的股权交易管理功能。

## 🎯 核心价值主张

1. **官方授权** - 字节跳动官方授权的股权交易平台
2. **合规交易** - 符合香港金融管理局（HKMA）合规要求
3. **透明高效** - 交易流程透明，降低尽职调查成本
4. **专业管理** - Carta 风格的股权管理工具

## 👥 用户角色

### 1. FA 管理员 (FA Admin)
- **角色描述**: 平台运营方，负责管理整个交易流程
- **核心职责**:
  - 审核买家 KYC
  - 管理资产交易
  - 促成交易达成
  - 追踪佣金收入

### 2. 经纪人 (Broker)
- **角色描述**: 负责撮合交易、管理客户关系
- **核心职责**:
  - 开发和维护买家资源
  - 创建和管理资产列表
  - 协调交易流程

### 3. 投资者/买家 (Investor/Buyer)
- **角色描述**: 寻求购买字节跳动股权的个人或机构
- **核心需求**:
  - 浏览可投资产
  - 提交购买意向
  - 管理投资组合
  - 申请出售持股

## 🔄 核心业务流程

### 流程一：投资者入场流程

```
1. 访问首页 → 2. 完成 KYC → 3. 登录账户 → 4. 浏览项目 → 5. 提交意向
```

**详细步骤**:
1. 投资者访问平台首页 (`/`)
2. 点击"Start KYC Verification"进行身份认证
3. KYC 通过后获得投资者账户
4. 登录投资者门户 (`/user/login`)
5. 浏览投资机会 (`/opportunities`)
6. 对感兴趣的项目提交购买意向（Inquiry）
7. FA 审核意向并安排后续流程

### 流程二：资产交易流程

```
1. 卖家委托 → 2. 创建资产 → 3. 上架展示 → 4. 买家询价 → 5. FA 撮合 → 6. 签约交割
```

**详细步骤**:
1. 卖家（员工或早期投资者）联系 FA 委托出售
2. FA 在后台创建资产 (`/dashboard/assets`)
3. 资产上架到机会页面供买家浏览
4. 买家提交购买意向（Inquiry）
5. FA 协调买卖双方价格和条款
6. 签署协议 (`/dashboard/agreements`)
7. 通过香港银行托管账户完成交割
8. 记录佣金 (`/dashboard/commission`)

### 流程三：FA 管理买家流程

```
1. 买家注册 → 2. KYC 审核 → 3. 添加到买家池 → 4. 推送项目 → 5. 跟进转化
```

**详细步骤**:
1. 买家完成 KYC 后进入待审核列表
2. FA 在 `/dashboard/buyers` 审核买家资质
3. 审核通过加入合格买家池
4. FA 使用 AI 工具进行邮件营销
5. 追踪买家意向和转化情况

## 💰 商业模式

### 收入来源

1. **交易佣金** - 交易金额的 1-3%
2. **咨询服务费** - 为高净值客户提供定制服务
3. **平台服务费** - 为机构投资者提供 API 接入

### 成本结构

1. **合规成本** - 牌照维护、审计费用
2. **技术成本** - 平台开发和维护
3. **运营成本** - FA 团队、客服支持

## 🔐 合规要求

### KYC/AML 合规
- 香港金融管理局（HKMA）监管要求
- 投资者适当性管理
- 反洗钱（AML）审查

### 交易合规
- 字节跳动官方授权
- 交易见证和法律保护
- 香港银行托管账户

## 📊 关键业务指标 (KPI)

| 指标 | 说明 | 目标值 |
|------|------|--------|
| GMV | 平台交易总额 | $1B+/月 |
| 活跃买家数 | 月活跃投资者 | 1000+ |
| 交易转化率 | Inquiry → Deal | 15%+ |
| 平均佣金率 | 交易佣金比例 | 2% |
| KYC 通过率 | 通过审核比例 | 80%+ |
