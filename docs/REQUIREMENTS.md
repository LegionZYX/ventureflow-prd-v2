## 🎯 产品愿景

打造全球领先的字节跳动股权二级市场交易平台，为 FA、经纪人和投资者提供专业、合规、高效的交易管理服务。

## 👤 用户画像

### 用户画像 1: FA 管理员 (Admin)

**基本信息**
- 姓名：张经理

## 🔧 非功能需求

### 性能要求
- 页面加载时间 < 2 秒
- 首屏渲染时间 < 1 秒
- API 响应时间 < 500ms

### 安全要求
- HTTPS 强制启用
- 密码加密存储
- 会话超时（30 分钟）
- CSRF 防护

### 兼容性要求
- Chrome 90+ ✅
- Safari 14+ ✅
- Firefox 88+ ✅
- 移动端响应式 ✅

### 可用性要求
- 系统可用性 > 99%
- 数据备份（每日）
- 故障恢复 < 1 小时

## 📊 数据模型

### 核心实体关系

```
User (用户)
├── Investor (投资者)
└── FA (财务顾问)

Asset (资产)
├── Listing (挂牌)
└── Transaction (交易)

Inquiry (询盘)
├── Status (状态)
└── FollowUp (跟进)

Deal (交易)
├── Agreement (协议)
└── Commission (佣金)
```

### 数据库表设计（简化版）

**users**
| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 用户 ID |
| email | string | 邮箱 |
| name | string | 姓名 |
| role | enum | admin/fa/broker/investor |
| kyc_status | enum | pending/approved/rejected |
| created_at | timestamp | 创建时间 |

**assets**
| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 资产 ID |
| name | string | 资产名称 |
| type | enum | common/preferred/option |
| valuation | number | 估值 |
| price_per_share | number | 每股价格 |
| volume | number | 交易量 |
| status | enum | active/sold/suspended |

**inquiries**
| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 询盘 ID |
| investor_id | uuid | 投资者 ID |
| asset_id | uuid | 资产 ID |
| amount_min | number | 最小金额 |
| amount_max | number | 最大金额 |
| status | enum | pending/review/meeting/completed |
| created_at | timestamp | 创建时间 |
